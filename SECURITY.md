# Security Policy

## Reporting

Report a suspected vulnerability privately to
[rinz0x0cruz@gmail.com](mailto:rinz0x0cruz@gmail.com). Include the affected URL,
the observed behavior, reproduction steps, and the potential impact. Do not
include credentials, personal data, malware, or other sensitive material unless
requested through a mutually agreed secure channel.

Reports are reviewed on a best-effort basis. This project does not currently
offer a bug bounty or guaranteed response timeline.

## Authorization And Scope

This reporting route does not grant authorization to test any system. Do not
test GitHub Pages infrastructure, third-party services, social profiles, or
projects linked from the portfolio. Avoid denial of service, social engineering,
automated scanning, data access, persistence, or actions that affect other users.

If you encounter sensitive information unintentionally, stop, preserve only the
minimum details needed to explain the issue, and report it privately.
